## 0.1.0

- Initial reusable Flutter intro package, independent of application state managers.
- Wrapped widgets, existing keys, and supplied widget targets.
- Automatic and manual playback with frequency/cooldown/maximum-play policies.
- Pluggable history storage and JSON serialization.
- Async preparation/actions, cancellation results, and lifecycle callbacks.
- Animated spotlight/arrow overlay, theming, and custom coach cards.
- Modal, scrolling, route/application lifecycle, input and accessibility handling.
- Replay, next/back/jump, pause/resume, skip/stop, retry, completion and reset APIs.
- Responsive Bloom example with durable history and a real interactive modal tour.
